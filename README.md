# Photo geolocator

This entry sends each unanswered JPEG to Claude Sonnet 5.5 with a visual-analysis prompt that asks it to compare text, road clues, vehicles, architecture, infrastructure, vegetation, terrain, and other visible evidence before narrowing down to a coordinate estimate. It reads the trial brief, obtains the photo list from the environment service, and sends the image inline through the Anthropic Messages gateway.

Photos are processed sequentially in the env's listed order, so both model requests and the final answer batch are independent of completion timing. Coordinates are validated and rounded to six decimal places. Model calls retry only transient HTTP statuses (408, 429, and 5xx) with a fixed backoff; gateway refusals and other failures are final for that call. If the first reply cannot be parsed, one small text-only follow-up asks the model to restate that recorded reply as JSON; a second parse failure leaves the photo unanswered. Main calls allow 3,072 output tokens so the requested evidence analysis has room to reach its final coordinate line, and rescue calls allow 256. With at most four attempts per call and at most two calls per photo, the 25-photo trial stays within the 200-request cap.
